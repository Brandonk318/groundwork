# Roadmap (proposed build order)

Each phase ships with tests, and nothing goes live without Brann's OK.

**Phase 0: Scaffold (done)**
Registry of 45, tiers table, safety policy (crisis, locks, anonymity, phone redaction), vault envelope crypto, real-delete wipe, health route, React shell with crisis button on every screen, 8 locales with Arabic RTL, docs, project skills.

**Phase 1: Safety floor and identity**
Auth (member, family and admin roles, adapted from Trade Circle), `crisis_button` (done), `relapse_protocol` (needs content), `safe_call_contacts`, `data_wipe` endpoint plus confirm UI, `mood_checkins`, `filters` and `locks` (policy done; storage, API and UI next), `read_aloud`, `multi_language` (human translations of crisis copy first).

**Phase 2: Community core**
`community_feed` (upgraded), `anonymous_posting`, `photo_posts`, `peer_messaging` (no phone numbers), `program_groups`, `milestone_celebrations`, plus moderation using the recovery-moderation skill.

**Phase 3: Reentry tools**
`reentry_checklist` (blocked on the 33 steps), `court_calendar` plus outbox reminders, `resource_directory`, `twelve_step_locator`, `counseling_referrals`, `document_vault` (paid; the crypto is done).

**Phase 4: Journey**
`journey_portfolio` (upgraded, private by default), `day_one_archive`, `progress_share_card`, `token_rewards`, `merch_rewards`.

**Phase 5: Work**
`job_board`, `resume_builder`, `application_tracker`, `interview_coach`, `micro_gigs` (connects to Brann's contractor network; parole caveat).

**Phase 6: Learning**
`courses` (both entries) on the academy video and quiz engine, with fresh curriculum: parole navigation, job interviews, relapse prevention, starting a small business. Use the course-generation skill.

**Phase 7: People**
`mentorship`, `accountability_partners` (2-to-1), `anonymous_qa`, `family_mode`, `needs_a_ride`, `geolocation`, `events`, `virtual_meetings`, `voice_notes`, `video_posts` (paid hosting).

**Phase 8: Upgraded showpieces**
`ai_matching` (blocked on the safety rules in open question 6) and `virtual_venue` (blocked on real venue photos).
