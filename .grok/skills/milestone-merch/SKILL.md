# Discreet milestone merch

Goal: gear someone can wear anywhere (work, family events, parole check-ins) that only people in the community recognize as a milestone.

## Design rules
1. **Discreet by default.** No "sober", "recovery", "addict", "jail" or "prison" printed large on the front. Meaning lives in a symbol, number system, color or small inside-hem print.
2. **Coded milestones.** Use a consistent system across the line, for example a mark that gains a stripe, segment or dot per milestone (30, 60, 90 days, 6 months, 1 year, then yearly). Write the key once and reuse it.
3. **Upscale, not novelty.** Clean type, tonal embroidery, premium blanks. It should look like a streetwear or lifestyle brand.
4. **Private story.** The full meaning can go on a hang tag, inside print or a QR code that opens a page the wearer chooses to share.
5. **No dates on the outside.** A visible sobriety date is personal info.

## For each concept, deliver
- Name and one-line story.
- Front, back and inside placements, with sizes in inches.
- Colorway (hex codes) and method (embroidery, screen print, DTG, woven label).
- Which milestone it marks and how the code shows it.
- A plain note on what a stranger sees and what an insider sees.

## Rules
- Use only the brand name Brann gives you; ask if none is set. Don't copy AA or NA symbols or other trademarks (the circle-triangle, "One day at a time" logos, etc.).
- Mockups and spec sheets only. Don't order, upload to a store or spend money without Brann's OK.
